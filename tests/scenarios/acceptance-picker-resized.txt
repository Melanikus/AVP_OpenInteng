# ACCEPTANCE (red first; Vasquez 2026-11-24, Bishop's card for beta.0; the owner: "Yes, same pickup"): A RESIZED COPY OF A STOCK PICKUP IS THAT PICKUP. A level can
# hold a stock pickup at another size (its SHPEXTFN's rescale isn't 1): its bytes, so its SHA-256, aren't the stock file's, and typed placement (shape_identity.h,
# exact SHA-256 only) left it unknown, so static. Now a tile with no row by its SHA-256 whose shape is a stock pickup's at ONE uniform scale (shape_resized.h:
# the same points times one scale greater than 0, within the files' rounding; the same polygons in the same order, the same texture names and places) takes that
# pickup's row: typed, its green border, and the words say "a resized copy of <stock file> (scale ...)".
# WHAT IT IS COMPARED WITH: only Steam's own pickup files on the machine, read from the lookup order's folders as the picker opens, each kept only when its bytes'
# SHA-256 is the row's (shape_picker_screen.cpp ReadStockPickups). The table holds no shapes, so before the first start's search makes them, nothing is typed by size.
# THE SCENARIO'S OWN GAME ({datadir}-resized-game, tests/scenarios/make_shape_game.cpp, each file by the editor's own extractor, so each is the file the first
# start's search writes): Invasion, and in <game>\shape_rifs Steam's own pickups at their own size: medbox01 from Derelict, armour01, pulse and smart from colony_c,
# flam01 from Jockey; and medbox01_var001 (medbox01 with its first point moved 1 mm: an EDITED shape at the stock size, a near miss that must stay unknown).
# Invasion's own medbox01, Armour01, pulse, Smart and Flam01 are rescaled copies (their tiles named as the folder's files: armour01, smart, flam01) (Dietrich, measured on 51dcdd42: 12 of its 21 shapes make no file). The folder's
# file of each name is "in this level", so the tile is drawn and placed from INVASION'S copy: that copy is what is compared and placed.
# THE STATE LINE: pickerresized "<tile>~<stock file>~<scale>~<worst mm>|..." (the tiles on the screen typed by their size); pickerstockpickups "<k> of <n> read in
# <ms> ms"; pickertyped and pickerhover as acceptance-picker-typed. The saved copy is read back by the game's own loader (verify_strategy): Type 4 (health).
