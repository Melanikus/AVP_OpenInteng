# (tests/scenarios/verify_level_same.cpp, tests/level_same.h). Every save runs inteng's prepare_for_output, which moves on every OBJHEAD1, SHPHEAD1, ENDTHEAD,
# ENUMHEAD and ASPRHEAD version counter, so the two copies are never the same bytes (926 bytes apart on Invasion); verify_level_same compares them chunk by chunk,
# every byte but those counters, and says SAME. A change-nothing check compares a save made BEFORE the action with one made after it ({save1} {save2}), never the
# stock file ({orig}): the game's own files hold stray bytes after their names that every save writes as zeros (level_same.h says more).
