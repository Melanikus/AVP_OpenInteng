# ACCEPTANCE (red first; Drake 11-17, camera-closeout-drake.md CAM-3 / CAM-7 / CAM-8): the camera SWINGS ROUND the rotation centre, on his path (Invasion, the file opened as a double click).
# inteng's manual (menu.txt): "/ + Rotation Keys: Rotate Camera Around Environment Using World Axes", "Number Pad / + Rotation: ... Using Camera Axes", "Scroll Lock + Object: Set Object For
# Rotation Axes". The mover FUN_0053db40 0x53dec0-0x53e071: with '/' (slot 0xbf) or numpad / (0x6f) held, the turn keys' turn swings the camera's place round DAT_00931110 and turns the camera by the
# same, so the centre stays where the camera sees it. The centre starts as the average place of the level's objects at every hub start (FUN_00470e70 from FUN_00447550 0x447652); Scroll Lock
# (FUN_004720c0) shows "Choose object for centre of rotation" at (200, 100) and "RMB or escape to cancel" at (200, 0x74) and puts it on the object or module the next left press hits.
# The state line's rotcentre: the centre, the camera's distance to it, its bearing round it, where the camera sees it (seenx / seeny / seenz along its own axes), waiting.
# (remember-number keeps ONE number: each quantity is kept and checked round a hold of its own.)
# RED on bishop-int (no rotcentre field; '/' does nothing: numpad 4 turns the camera where it is, so it sees the centre elsewhere and its bearing stays).
start-args C:/Users/Melanikus/source/AvP-builds-excluded/AvP-play-release/avp_rifs/Invasion.RIF
pictures on
state

# CAM-7: the centre is the average of Invasion's objects (each place / their count, added)
expect-number rotcentre waiting 0 0
expect-number rotcentre x -7577 -7573
expect-number rotcentre y -9066 -9062
expect-number rotcentre z 55636 55640
# CAM-8: Scroll Lock waits, with inteng's two lines. The wait is MODAL (FUN_004720c0's loop reads only the mouse): Esc on its own does nothing, no key acts (Insert starts no zoom), nothing moves
# (numpad 4 held turns nothing); a press with Esc held gives up (0x472139), the centre as it was

key ScrollLock
expect-number rotcentre waiting 1 1
expect-field-has hierarchylines 6@200:Choose object for centre of rotation
expect-field-has hierarchylines 7@200:RMB or escape to cancel
picture 1

# no screen frame runs meanwhile: H held does not raise the hub's view distance

# the right button gives up too
